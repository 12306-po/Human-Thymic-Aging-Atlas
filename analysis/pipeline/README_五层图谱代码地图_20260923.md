# 人类胸腺五层衰老图谱：代码地图与证据边界

更新日期：2026-09-23

本目录是当前唯一主代码库。`scripts/` 和旧 `图片代码/` 已移入归档，不再作为服务器运行来源。

## 总体判断

现有代码与“五层 atlas + 探索性 Thymic Biological Age Score”的方向基本一致，但不是五层均已完成的最终版。

| 模块 | 当前实现 | 结论 |
|---|---|---|
| Layer 1 Cell-composition aging atlas | `08_build_pseudobulk_and_composition.py`、`27_composition_aware_age.py`；CLR `age + sex`、HC3、BH、LODO 稳定性、Dirichlet sensitivity | **基本完成**；解释为相对组成变化，不能写绝对细胞数上升/下降 |
| Layer 2 Cell-type-specific transcriptional atlas | `22_age_adjusted_pseudobulk_limma.R`、`29_expression_age_shape_sensitivity.R`、`35_human_pathway_age_model.R` | **基本完成**；主效应为 sex-adjusted donor-level limma-voom |
| Layer 3 Developmental-stage aging atlas | `17_external_human_validation.R`、`17b_state_donor_counts.R`、`32_build_human_thymic_aging_atlas.py` | **部分完成**；目前是 GSE195812 developmental localization/context，尚非独立 aging validation，也尚未形成经校验的阶段分数 |
| Layer 4 Regulatory aging atlas | `16_pathway_and_TF_interpretation.py`、`19_mouse_scATAC_validation.R`、`20_final_multiomics_integration.py`、`28_cross_species_sex_adjusted.R`、`33–34` | **部分完成**；TF→motif→peak→target 已有候选链路，但 1 young + 1 aged mouse 只能作机制性/假说生成支持 |
| Layer 5 Donor aging trajectory | `26_fully_nested_donor_ML.py`、`31_build_thymic_aging_score.py` | **部分完成**；已有连续年龄 OOF 位置和年龄偏差校正，但尚未建立独立验证的轨迹状态或 Young-like/Transition/Involution-like 切点 |
| Global exploratory score | `26_fully_nested_donor_ML.py`、`31_build_thymic_aging_score.py` | **已有 proof-of-concept**；只能称 internally cross-validated exploratory score |
| HumanThymusFormer attribution | `14b_strict_oof_HumanThymusFormer.py`、`15_interpret_HumanThymusFormer.py` | **已有 strict-OOF attribution**；用于 post-hoc representation/attribution，不与 Elastic Net 做“谁更强”的竞争 |
| Five domain scores | 暂无正式定义和预注册的特征集 | **未完成** |
| Independent human calibration | 暂无带准确年龄的独立成人人类胸腺队列 | **未完成** |

## 当前服务器主运行链

1. `00`–`24`：基础数据、细胞注释、pseudobulk、候选特征、初版 ML/DL、发育背景、小鼠 RNA/ATAC 与敏感性。
2. `25`–`30`：投稿级 donor manifest、fully nested ML、composition-aware model、sex-adjusted cross-species comparison、age-shape sensitivity 与 result packet。
3. `31`–`36`：探索性胸腺年龄评分、atlas 源表、人类参考效应、跨数据集证据整合、方向性通路分析和外部 GEO metadata 冻结。
4. `99_make_paper_figures.py` + `fig_paper/` + `100_check_paper_figures.py`：组图和图件审计。新结果出来后必须更新图代码，不能直接复用旧数值。

## 投稿表述边界

- 允许：`donor-resolved continuous-age atlas`、`internally cross-validated exploratory thymic age score`、`age-adjusted thymic age deviation`。
- 不允许：`clinically validated biological-age clock`、将小鼠数据写为人类 score 的 external validation，或将 1+1 小鼠写成 conserved mechanism。
- 0–100 当前若使用，只能是 18 供者内的相对百分位，不得设置未经外部校准的临床切点。
- `Thymopoiesis / Selection / Maturation-export / Inflammatory remodeling / Regulatory aging` 五个分维度评分在特征集冻结、方向规则和外部校准完成前，仅作预设分析方案。

## 下一轮必须新增的分析

1. 将 Layer 3 从“候选基因在发育状态中定位”升级为按预定义发育模块汇总的 donor-level aging effects。
2. 对 Layer 4 固定 TF–motif–peak–target 映射版本，并在有生物学重复的外部数据集上测试方向一致性。
3. 对 Layer 5 输出仅基于 OOF 预测的连续坐标；类别边界必须在独立队列上设定。
4. 五个 domain score 需要预先冻结基因/细胞/通路集、方向、标准化方法和缺失值规则，不能根据当前 18 人结果反复挑选。
5. 找到独立人类队列后，freeze score 后仅做一次外部测试和必要的 recalibration。
