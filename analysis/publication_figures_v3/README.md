# Publication figures v3

This folder rebuilds Figures 1–5 with one restrained visual system: Times New
Roman, 7.5–9 pt text at final width, age-up red, age-down blue, significant
effects in saturated colour, and non-significant results in grey.  The output
formats are PDF, SVG, 600-dpi PNG, and 600-dpi TIFF.

The local release contains enough source tables to rebuild Figures 2–5.  The
single-cell UMAP and marker-dotplot panels in Figure 1 require exported panels
from the server-side annotated object.  They may be rasterized inside the
otherwise-vector PDF/SVG because of the large point count; text, axes and all
other panels remain vector.

```bash
python plot_main_figures_v3.py \
  --root /data/zxy/projects/human_thymus_age_ML_DL \
  --atlas-release /path/to/Human_Thymic_Aging_Atlas/release/data \
  --audit-dir /data/zxy/projects/human_thymus_age_ML_DL/figures_final_revised \
  --umap-panel /path/to/figure1_umap_panel.png \
  --marker-panel /path/to/figure1_marker_dotplot_panel.png \
  --output /data/zxy/projects/human_thymus_age_ML_DL/figures_publication_v3
```

The program fails if the required source tables are absent.  It never
digitizes values from a screenshot.  `--umap-panel` and `--marker-panel` are
display-only exports generated by the primary annotation workflow.
